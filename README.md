# Hollow

**Hollow** is a lightweight, all-in-one AI study platform designed to let you connect and use multiple AI providers from a single, simple interface.

Instead of being locked into one AI provider, Hollow allows you to bring your own API keys and connect to different services. It currently supports **23+ existing free providers**, along with an **OpenAI-compatible provider**, giving you the flexibility to experiment with different models and services in one place.

## ✨ Features

* 🤖 **23+ free AI providers** supported
* 🔑 **Bring your own API key**
* 🔌 **OpenAI-compatible API support**
* 💬 Chat with connected AI models from one interface
* 📚 Designed specifically with **studying and learning** in mind
* ⚡ Lightweight and simple
* 🌐 Runs directly in the browser
* 📄 **The entire platform is contained in a single HTML file**

## 🚀 Why Hollow?

Hollow was built around a simple idea: make it easy to experiment with different AI providers without needing a complicated application or large codebase.

The most unique part of the project is that **the entire application lives inside a single HTML file**. No large framework setup, complicated build system, or collection of project files is required.

Despite being contained in one file, Hollow can connect to multiple AI providers and provide a complete interface for interacting with them.

## 🔑 Bring Your Own API Keys

Hollow does not require you to rely on a single built-in AI service. You can connect supported providers using your own API keys and choose which provider you want to use.

This makes Hollow useful for experimenting with different models, comparing providers, and finding the tools that work best for your workflow.

## 🛠️ Built With

Hollow is intentionally kept extremely simple:

* HTML
* CSS
* JavaScript
* AI provider APIs

**No complicated setup. One HTML file.**
